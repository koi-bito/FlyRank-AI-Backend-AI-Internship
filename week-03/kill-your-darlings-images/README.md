## 3. Where Real Captures Beat AI Every Time

1. **The Swagger UI Spec:** An AI-generated mock of an API document might look pretty, but it often invents non-standard status codes or inconsistent JSON keys. A real screenshot of Swagger UI showing `200`, `201`, `204`, and `400` demonstrates that the developer actually booted the server and verified the HTTP boundaries.
2. **The Inngest Retry Waterfall:** Capturing a real dashboard showing attempt 1 failing, waiting 2 seconds, attempt 2 failing, and attempt 3 succeeding proves understanding of distributed systems backoff better than any conceptual diagram.
3. **The Developer Photograph:** AI-generated "corporate headshots" look plastic, unnerving, and dishonest. A real, friendly photo builds genuine trust for the 20-minute walkthrough call.
